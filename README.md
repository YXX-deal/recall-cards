# recall-cards

学习知识卡片闭环插件：**问答自动制卡 → 卡片自动关联 → 再次提问时先反问、并提醒你当时为什么问**。

解决的问题：日常学习中遇到陌生知识点，问完 AI 就忘，下次遇到又从头问。recall-cards 把每次提问沉淀成一张带"提问动机"的卡片，让下一次相遇变成一次主动回忆，而不是重复查询。

## 工作方式

> **按对话显式开启**：默认不全局自动触发。在某个对话里说"开启卡片记录"或运行 `/recall-cards:on` 后，本对话才进入制卡/反问闭环；新对话默认关闭，需重新开启。说"关闭卡片模式"可停止。

1. **即时解答**：开启后，你在学习中问知识点问题（"X 是什么""X 和 Y 有什么区别"），它先检索你的卡片库。
2. **命中旧卡 → 反问模式**：不直接给答案，先提醒你上次提问的场景（"你上次是在做题时问的"），再基于旧卡考你一个回忆性问题；你作答后评定记录，然后完整回答当前问题。随时可以说"直接告诉我"跳过。
3. **未命中 → 先回答，再暂存草稿**：先完整回答问题，再把要点存成一张**待确认草稿**（问题、纯文本浓缩答案、**提问动机**、大类、标签与检索词）。草稿不即时入库、不进复习，你核对/纠错后说"确认"或在管理台点"确认入库"才转正——AI 答错时能在入库前改，不必反复改卡。
4. **自动关联**：新卡与已有卡片语义相关（前置/对比/应用）时自动建立双向链接，知识图谱随学习自然生长。
5. **间隔复习**：`/card-review` 按 SM-2 简化算法（good/hard/forgot 三档）调度到期卡片，复习时同样先唤起动机场景再反问。
6. **知识图谱**：`/card-map` 生成自包含 HTML 力导向图，**按大类聚簇分离**（各大类独立成簇、彼此分开）、**可筛选只看单一大类**、关系标签、到期高亮、草稿虚线、悬停查看大类与提问动机。
7. **图形管理台**：本地网页管理台（仅监听 127.0.0.1），**左侧多级文件夹树**（展开/计数/重命名/移动子树/删除/新建 + 面包屑，卡片/复习/图谱/统计按文件夹子树作用域）、卡片搜索/浏览/编辑/新建/删除、**列表批量选择 + 跨文件夹移动 + 删除（均可撤销）**、大类彩色标签筛选与排序、**待确认草稿托盘与一键入库**、带关系类型的关联管理（**关联卡片可点击直达详情**）、按钮式复习（**各档间隔预览 + 记忆遗忘曲线**）、按大类上色的图谱（可按文件夹过滤）、大类/标签分布统计。服务由 SessionStart hook 自动拉起并跨会话驻留，可在界面头部"会话自启动"开关关闭；打开时优先用系统默认浏览器。

## 安装（装完即用）

1. 环境：本机装有 Node.js ≥ 18（零第三方依赖，无需 npm install）。
2. 在 Qoder 扩展视图选择「安装本地插件」，导入 `recall-cards.zip`（或直接把源码目录交给 Qoder 安装）。
3. 安装后无需任何手动启动：每次会话启动时插件 hook 自动在后台拉起管理台服务（仅监听 127.0.0.1，已运行则跳过）。
4. 直接使用：说"打开管理台"或运行 `/recall-cards:ui`，浏览器即开 `http://127.0.0.1:47800/`；说"开启卡片记录"或 `/recall-cards:on` 进入学习闭环。首次使用卡片库为空，提问即开始积累。

## 使用

| 场景 | 操作 |
| --- | --- |
| 开启学习卡片模式 | 说"开启卡片记录/进入学习卡片模式"，或 `/recall-cards:on`（仅本对话生效） |
| 日常学习提问 | 开启后直接问知识点问题，自动触发制卡/反问 |
| 复习到期卡片 | `/card-review` 或"帮我复习卡片" |
| 查看知识图谱 | `/card-map` 或"看看知识图谱" |
| 图形化管理 | 说"打开管理台"/"卡片界面"，或 `/recall-cards:ui`（短别名）、`/recall-cards:card-ui`；自启动开启时零命令，浏览器直接开 `http://127.0.0.1:47800/` |
| 管理卡片 | "列出我的卡片""改一下某张卡的动机""删掉某张卡"（删除会先确认） |

## 存储

- 默认目录：`~/.recall-cards/`（跨工作区持久，学习记录不随项目切换丢失）。
- 可用环境变量 `RECALL_CARDS_HOME` 覆盖位置。
- `cards/*.md`：卡片本体（Markdown + YAML frontmatter，可直接阅读、手改、迁移）。
- `index.json`：检索索引，由脚本维护。
- `config.json`：`autoStart` 开关（界面头部可切换），决定 SessionStart hook 是否自动拉起服务。
- `graph.html`：图谱页面，随时重新生成。
- 全部数据仅存本地，不上传；插件不指示把密码、令牌等敏感信息写入卡片。
- 管理台服务只绑定 127.0.0.1，写接口仅接受本机 JSON 请求并校验 Origin，局域网/外网不可访问。

## 组件

- `skills/recall-cards/`：主 Skill（触发判定、检索、反问、制卡、关联、复习、图谱、管理）。
  - `references/card-format.md`：卡片格式规范与示例。
  - `references/quiz-protocol.md`：反问话术与 good/hard/forgot 评定规则。
  - `scripts/cards.mjs`：零依赖 Node 脚本（索引/中文双字分词检索/SM-2 简化调度/双向链接/图谱生成/统计）。
  - `scripts/serve.mjs`：管理台本地服务（loopback HTTP + JSON API）。
  - `assets/ui.html`：管理台单页界面（卡片/复习/图谱/统计四个页签）。
- `commands/on.md`（开启学习卡片模式）、`commands/card-review.md`、`commands/card-map.md`、`commands/card-ui.md`、`commands/ui.md`（短别名）：斜杠命令。
- `hooks/hooks.json` + `bin/ensure-ui.mjs`：SessionStart 时幂等确保管理台服务驻留（先探针后 detached 拉起，服务端另有同目录单例探针）。
- 无 MCP、Agent——本工作流不需要。

## 设计说明

- 关键词检索（脚本，中文双字分词 + 字段加权）负责粗筛，语义关联判断交给 AI，各取所长。
- 复习调度为 SM-2 简化版：good 按 ease 倍增间隔，hard 间隔 ×1.2，forgot 重置为 1 天并扣 ease。
- 反问协议限制最多 1–2 轮、一次一问、只考卡内内容，用户可随时叫停——回忆是助力，不是关卡。
- 卡片极简：问题原样、答案 ≤6 行、动机单处存放；回答与简报不附加未问内容。
- 图谱边带关系标签（前置/对比/应用/相关），游离卡片独立分区并与知识网络保持距离。
